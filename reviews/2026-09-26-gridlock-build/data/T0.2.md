## Declared deviations and questions

- `meta.build_time` is `null` so `meta.json` is byte-identical across rebuilds; a SHA-256 digest identifies the input set. The lead confirmed the nullable contract.
- The default build consumes committed parsed CSVs. Re-extracting PDFs is a separate source update, so changes in extraction cannot silently change reviewed project rows. `--refresh` explicitly refreshes the public HIFLD download and was not run because this task is offline.
- Open question for a later source update: should PDF re-extraction become a separate reviewed command with a before/after row table?
