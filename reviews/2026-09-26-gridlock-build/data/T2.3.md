# DATA T2.3 — screening savings estimates

## Formula and hand calculations (recorded before model code)

This is a **team-assumption screening estimate**, not an observed saving, a public industry rate, or a claim that two projects can share an asset. Both planned savings fractions and the line-cost proxy will be labelled `team assumption` dated 2026-09-26 in `data/manual/assumptions.json`. Plan costs remain the printed source amounts, including any existing discrepancy or below-threshold flags. SERTP costs are absent in the loaded extract and are never filled in as source facts.

Decision order for each overlap:

1. If either in-service year is unknown, `unknown_year`, with null bounds and an explanatory basis.
2. If the absolute year gap is **greater than two**, `timing_too_far`, with null bounds. Exactly two years remains eligible.
3. Select the smaller usable printed plan cost when either project has one. This conservatively caps the priced scope and prevents adding two budgets. If only one project has a printed cost, price only that one project's scope and say the partner cost is unavailable. The source's `cost_flags` stay on the project and any flags on the chosen plan cost are named in the savings basis. Let reference cost be `C` USD.
4. With no usable plan cost, use stated positive mileage only from `new_line`, `rebuild_line` or `reconductor` projects. Take the shorter stated line mileage `M` if both sides provide one; the potentially coordinated scope cannot exceed it. This is a **proxy**, not a source project cost. Team-assumed capital-cost range is $1,000,000–$3,000,000 per line mile, so reference cost is `[M × 1,000,000, M × 3,000,000]` USD. The savings basis must say `proxy`, identify the project and mileage, and say the physical shared scope is unverified.
5. If neither a plan cost nor eligible mileage exists, `no_cost`, null bounds and a reason. Likewise, if the team's rounding precision collapses a positive range, report `no_cost` instead of a fabricated positive bound.

For either reference-cost path, apply the team-assumed **1%–3% coordination fraction**: raw savings bounds are `[C × 0.01, C × 0.03]` for plan cost, or `[M × 1,000,000 × 0.01, M × 3,000,000 × 0.03]` for the proxy. Round each bound to the nearest **$1,000**, half up, as declared on the fraction assumption. Publish a `range` only if the rounded bounds are positive and strictly ordered; include the relevant assumption IDs and a basis that labels the result an estimate. Savings never alter pair score or rank.
