## Deviations and other-lane needs

No contract change. Substation suggestions are limited to a placed Point project with one named endpoint whose location evidence names it and whose source or project name identifies it as a substation. This avoids assigning a made-up station coordinate to an unplaced or ambiguous project. Project suggestions include placed lines using a coordinate already present in their GeoJSON geometry.

For API: no patch needed from another lane. `SearchResult.ref` is null for Census places and the project ID for project or substation suggestions.

Open questions: none for T2.8a.

2026-09-26 lesson: A search result with coordinates needs a direct path back to a validated local geometry or place record, especially for names that also appear in unplaced projects.
