## WEB contract

`GET /api/overlaps/{id}` returns `{overlap, project_a, project_b, savings, sources}`. `sources` is an ordered two-item array matching each project's `properties.source`; `savings` contains status, low/high, basis, and assumption IDs. Unknown IDs return the normal typed 404 error.

Document ID mapping for local links:

| Source `doc` value | Local URL | File served |
|---|---|---|
| `SCRTP Planned Facilities 2026-2030 $2M & Above` | `/api/sources/desc-scrtp-2026-2030` | `data/raw/desc_scrtp_2026_2030.pdf` |
| `SERTP 2025 Regional Transmission Plan (Nov 26 2025)` | `/api/sources/sertp-2025-rtp` | `data/raw/sertp_2025_rtp.pdf` |

Append `#page=<source.page>` for a project citation. `GET /api/export/overlaps.csv` accepts the list's project, band and cross-state filters and exports every matching pair, independent of list pagination.
