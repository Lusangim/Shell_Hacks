## Deviation, handoff and lesson

**Declared deviation:** The built set has **zero `lines_cross` overlaps among 489**, so no real ID can cover that requested class. The eval manifest does not synthesize or relabel one. DATA/lead should treat this as an upstream coverage gap; a future legitimate built crossing can be added to a new eval version while keeping these held-out IDs sealed.

**For API:** `server.brief_template.make_template_brief(pair, project_a, project_b, contacts)` and `tests.eval.grader.grade_brief(brief, pair, project_a, project_b, contacts)` are the offline baseline and gate for later brief work. `load_contacts(path)` supplies the whitelist. No other-lane patch is required for this commit. The pre-existing untracked `debug.log` was not read, edited, or staged.

**Open question:** The two Goshen naming forms are source names; the loaded rows do not establish whether they represent distinct physical sites. Keep the names verbatim and verify source drawings before describing a shared asset.

**Lesson (2026-09-26):** A real-data eval can expose a missing overlap class and still give an honest, useful 30-case baseline without manufacturing an example.
