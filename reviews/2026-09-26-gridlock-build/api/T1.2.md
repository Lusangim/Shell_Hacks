## Deviations and dependencies

- `Health` and `Basemap` response models are in `server/app.py`; the frozen `server/schemas.py` has no matching types. JSON API routes have typed response models. The static HTML `/` route declares `response_model=None` because it returns a file.
- The committed test folder uses `projects.json`. A configured artifact directory accepts that fixture name only when `projects.geojson` is absent. The default production directory requires `projects.geojson` and all four valid artifacts. Live production validation awaits DATA T0.3b/T1.5.
- `/` serves `web/index.html` when WEB T1.3 adds it; `/web` serves local assets. No web shell was in this worktree at test time.
